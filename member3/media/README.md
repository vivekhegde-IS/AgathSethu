# Member 3 Media Directory

This directory stores demonstration and evaluation media for Member 3:

- `videos/`: Camera recordings and junction streams (e.g. `camera_junction_1_v22_final_visible_anpr_recording.mp4`, `violation_video.mp4`)
- `evidence/`: High-resolution violation captures and video clips

> **Note:** Video files (`*.mp4`, `*.mkv`, etc.) are excluded from git via `.gitignore` to keep the repository lightweight. Place your local video assets directly in these folders or in `member3/frontend/public/evidence/`.
